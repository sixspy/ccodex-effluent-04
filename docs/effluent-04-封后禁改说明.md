# effluent-04 封后禁改取舍说明（当班封死）

- 核销槽位：排污丁 · 第 4 槽 / 污水域核销丁
- 事故批次：**SM-D22**（封批代 G2 已生效，监控台仍可回写 COD，快照曲线与正式指标错位，对账假绿）
- 落档时间：2026-11-25 当班

## 取舍：取「甲路径」，不与乙路径折中并存

题意给出两条互斥正确性口径，必须二选一并当班封死：

- **甲路径（本班采纳）**：封批代一旦生效，指标正式表（`sample_batches.metrics` 的
  `cod / nh3n / tp` 三列语义）**一律零改并拒写**。任何会话、任何入口（监控台回写 API、
  直连库硬 UPDATE、血缘/对账旁路）都不得改写正式指标。
- 乙路径（封后修订只进影子草稿 → 解封校验 → 原子升正，否则草稿作废）：**本班不采纳、
  不实现修订/升正通道**。库内 `metric_shadow_drafts` 仅作为 effluent-04 事故遗留影子修订的
  **取证只读表**，不存在任何从影子草稿回写/升正正式表的 API 或作业。

为避免「折中并存」的指控，明确封死以下边界：

1. 封批代生效的唯一判据：`discharge_seals` 存在 `status='已封批'` 记录（封批页「封批代已生效」标记同源）。
2. 采样服务指标回写端点对已封批批次一律 `409`，错误码 `metric_frozen_after_seal`，
   说明与审计动作均带偏航定性串 **「封后禁改偏航」**，并先落 `deviation_log`/审计再拒写。
3. 数据库层有触发器 `trg_eff04_metrics_freeze` 兜底：封批生效后任何对 `metrics` 列的硬
   UPDATE 都被 `RAISE(ABORT ... '封后禁改偏航 ...')` 中止，正式指标列零改。
4. 同批两路回写必须抢批锁 `sample:{sample_id}`（`effluent_locks`），后到者 `409 lock_busy`，
   且只在 `contention_log` 留「争用失败」痕，败方零写入。批锁判定先于封批只读判定，
   争用痕不得被封批标记判断替代。
5. 血缘服务默认只读正式层（`layer='official' AND promoted=1`）；未升正影子草稿及其
   血缘边（`layer='shadow' / promoted=0`，含事故边类型「封后影子修订」）一律不得混入
   `/api/lineage` 与封批/采样/血缘页面主表。
6. 对账服务对已封批批次以封批快照（`discharge_seals.snapshot_metrics`，与
   `sample_generation` 同代）为合格判定源，合格灯携带 `lamp_generation`；正式列与快照
   不一致时判漂移并亮不合格，杜绝用被硬改后的列继续假绿。
7. 排放口页曲线点直接取正式指标行自带时间戳（`adjudicated_at ?? created_at`），
   点戳与正式指标同戳，不允许前端另造时间轴。

## 五页账实同态口径

| 页面 | 同态约束 |
| --- | --- |
| 封批页 | 「封批代已生效 · G{n}」标记与 `discharge_seals` 行同源可读 |
| 采样页 | 选中封批生效批次后 COD/氨氮/总磷三个输入 `readonly`，回写必被拒 |
| 血缘页 | 主表仅正式层；未升正影子修订只在隔离区可见，绝不混入 |
| 对账页 | 合格灯代次 = 封批快照代次；漂移即红灯并显示「封后禁改偏航」 |
| 排放口页 | 曲线点 = 正式指标 + 指标行同戳；另标封批快照代次点 |
